## 🇬🇧 English Version

### About This Project
This repository contains the validated front-end codebase for `Kasa`, a modern real estate rental web application. Built during my web development training, this project transitions the architecture from static/vanilla web development to a modern single-page application (SPA) paradigm powered by React, Vite, and React Router.

### What I Did
* **Modern Tooling & SPA Architecture:** Initialized and configured a fast, lightweight development environment using **Vite** and **Node.js**, leveraging React JSX for clean, component-driven UI architecture.
* **Declarative Routing & Error Handling:** Implemented client-side navigation using **React Router**, setting up dynamic route matching (e.g., housing detail pages) and seamless 404 fallback routing.
* **Custom State Management & Caching System:** Designed a clean, decoupled service and hook architecture ([view code implementation](https://github.com/cha-mas/kasa/blob/main/src/lib/properties)) to manage data fetching, state caching, and error handling effectively without unnecessary third-party overhead.
* **Modular SASS & CSS Animations:** Developed custom, reusable UI components (interactive collapse accordions, image carousels, rate ratings) styled with modular SASS and smooth CSS transitions.

### Skills & Tools Used
* **React & React Router:** Functional components, hooks, JSX, single-page application routing, and state orchestration.
* **Vite & Node.js:** Modern build tooling, fast hot-module replacement (HMR), and dev environment runtime.
* **Architecture Pattern:** Custom service abstraction layer, specialized custom hooks (`lib/properties`), and isolated error boundaries.
* **SASS (SCSS):** Nesting, mixins, variables, and responsive layout styling.
* **Git & GitHub:** Feature-based version control and repository management.

## 🇫🇷 Version Française

### À propos de ce projet
Ce dépôt contient le code front-end validé du projet `Kasa`, une application web moderne de location immobilière entre particuliers. Réalisé dans le cadre de ma formation, ce projet marque la transition vers une architecture de Single Page Application (SPA) développée avec React, Vite et React Router.

### Ce que j'ai fait
* **Outillage Moderne et Architecture SPA :** Configuration d'un environnement de développement rapide et performant avec **Vite** et **Node.js**, en utilisant React JSX pour une approche modulaire basée sur des composants réutilisables.
* **Routage Déclaratif et Gestion des Erreurs :** Configuration de la navigation côté client avec **React Router**, incluant la gestion dynamique des routes (pages de détails des logements) et une redirection fluide vers une page 404 dédiée.
* **Système Découplé de Gestion d'État et Cache :** Conception d'une couche d'abstraction propre séparant les services et les hooks ([voir l'implémentation](https://github.com/cha-mas/kasa/blob/main/src/lib/properties)) pour gérer la récupération des données, le stockage en cache et le traitement des erreurs en toute autonomie.
* **SASS Modulaire et Animations CSS :** Intégration de composants d'interface interactifs (accordéons dépliants, carrousel d'images, notation par étoiles) stylisés avec SASS et agrémentés d'animations CSS fluides.

### Compétences et Outils Utilisés
* **React & React Router :** Composants fonctionnels, hooks, JSX, routage SPA et gestion des états d'interface.
* **Vite & Node.js :** Tooling moderne, rechargement à chaud (HMR) et environnement d'exécution local.
* **Architecture applicative :** Couche de service sur mesure, hooks personnalisés dédiés (`lib/properties`) et gestion explicite des erreurs.
* **SASS (SCSS) :** Variables, mixins, imbrications et mise en page adaptative.
* **Git & GitHub :** Gestion de versions et suivi du code source.
